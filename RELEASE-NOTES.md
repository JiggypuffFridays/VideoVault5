# VideoVault 5.0.0 — the final, free build

VideoVault is now **free**. This is the last planned release, and it's built to keep
working on its own.

**Download:** `VideoVault Installer v5.exe` below.
Windows · Premiere Pro or After Effects.

## What's new
- **Self-maintaining.** The download engine (yt-dlp) updates itself automatically, so
  downloads keep working with no new release and nothing to install by hand.
- **Cleaner, safer build.** Rebuilt from the engine up — no background license checks,
  no hidden services, no auto-run executables left in system folders.
- **Smooth upgrade.** If you had VideoVault 3, the installer removes it and carries your
  download folder and history straight into 5 — nothing to redo.
- **Better downloads.** Prefers Premiere-native H.264/MP4, handles TikTok / Instagram /
  Facebook / X / Reddit / Twitch, playlists, 4K, trimming, and browser cookies for
  restricted videos.

## Install
1. Run the installer and approve the Windows prompt.
2. In Premiere Pro / After Effects: **Window ▸ Extensions ▸ VideoVault**.

It isn't code-signed, so Windows SmartScreen may show a one-time "unknown publisher"
notice — choose **More info ▸ Run anyway**.
